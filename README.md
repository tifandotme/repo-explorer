## Prerequisites

- Node.js version **22**
- Bun (we only use the package manager)

## Getting Started

1. Install dependencies:

```bash
bun install
```

2. Run development mode

```bash
bun run dev
```

3. The app will be accessible at `http://localhost:3000`
